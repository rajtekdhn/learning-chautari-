Tek Raj Kapadi — Learning Chautari (Multi-page version)
=========================================================

यो version मा हरेक मुख्य menu item (Grammar, Grade 11/12, Classes,
Gallery, TSC Materials, About, Contact, Notices) को छुट्टै HTML page
छ, र homepage (index.html) बाट ती सबैमा link गरिएको छ।

Files:
- index.html      -> Home page
- grammar.html     -> Grammar rules + exercises (Resources)
- grade.html       -> Grade 11/12, SEE, TSC exam prep
- classes.html     -> Classes / Spoken English / New Courses
- gallery.html     -> Gallery
- tsc.html         -> TSC Materials
- notices.html     -> Notices
- about.html       -> About / "Why study here?"
- contact.html     -> Contact form
- style.css        -> Original design (untouched)
- nav-extra.css    -> New styles for dropdown submenus + inner page headers
- teacher-photo.svg -> Placeholder photo (replace teacher-photo.jpg with your real photo)

Menu / Submenu:
Top navigation bar (green) मा GRAMMAR, GRADE 11/12, CLASSES, GALLERY,
र TSC MATERIALS मुनि "▾" arrow छ — click/tap गर्दा dropdown submenu
खुल्छ, जसले त्यही page भित्रका section हरूमा सिधै लैजान्छ।
Example: GRAMMAR ▾ dropdown मा Tenses, Articles, Prepositions,
Active & Passive Voice, Tag Questions, Grammar Exercises छन्।

चलाउने तरिका:
1. सबै file हरू एउटै folder मा राख्नुहोस् (यसरी नै जस्तो छ, structure नबिगार्नुहोस्)।
2. index.html मा double-click गर्नुहोस् — Chrome/Edge मा खुल्छ।
3. Online राख्न चाहनुभयो भने यही folder GitHub Pages/Netlify/Vercel मा upload गर्नुहोस्।

थप्न सकिने:
- नयाँ topic थप्न सम्बन्धित page मा गएर ".acc-item" वा ".dl-list li" block copy-paste गर्नुहोस्।
- नयाँ page थप्न चाहनुभयो भने अरू page जस्तै header/nav/footer copy गरेर नयाँ file बनाउनुहोस्,
  अनि सबै page को <nav class="mainnav"> मा link थप्नुहोस्।
